# 识字小花园支持网站

此仓库仅包含 iPhone / iPad App「识字小花园」的公开使用帮助与隐私说明，不包含 App 源码、构建文件或用户学习数据。

- [使用帮助](https://github.com/allonli/literacygarden-support/blob/main/support.md)
- [隐私说明](https://github.com/allonli/literacygarden-support/blob/main/privacy.md)
- [公开支持区](https://github.com/allonli/literacygarden-support/issues)

请由家长提交问题。Issues 和附件公开可见，不要提交孩子真实姓名、Apple 账户、密码、学习备份或未遮挡的个人截图。

以上 Markdown 页面可直接公开阅读。仓库同时保留不含统计脚本、广告或第三方前端依赖的静态 HTML。GitHub Pages 构建已启用；由于账户原有自定义域名的项目路径尚不可用，暂不将该地址作为正式支持链接。GitHub 自身的服务日志与账号处理见其[隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
