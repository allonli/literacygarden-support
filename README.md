# 识字小花园支持网站

此仓库仅包含 iPhone / iPad App「识字小花园」的公开使用帮助与隐私说明，不包含 App 源码、构建文件或用户学习数据。

- [使用帮助](https://allonli.github.io/literacygarden-support/support.html)
- [隐私说明](https://allonli.github.io/literacygarden-support/privacy.html)
- [公开支持区](https://github.com/allonli/literacygarden-support/issues)

请由家长提交问题。Issues 和附件公开可见，不要提交孩子真实姓名、Apple 账户、密码、学习备份或未遮挡的个人截图。

网站使用 GitHub Pages 从 main 分支根目录发布，无统计脚本、广告或第三方前端依赖。GitHub 自身的服务日志与账号处理见其隐私声明。
